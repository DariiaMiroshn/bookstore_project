# Bookstore Project (Django)

Веб-додаток книжкового інтернет-магазину на Django з підтримкою асинхронних views, інтернаціоналізації (i18n), інтеграцією платежів через Stripe Checkout, відправкою email та автоматизованим тестуванням через pytest.

---

## Основний функціонал
- **Каталог книг та пошук:** перегляд списку книг із пагінацією, фільтрація за категоріями, детальна сторінка книги.
- **Кошик покупок (Cart):** додавання, зміна кількості та видалення книг через сесії.
- **Оформлення замовлення (Checkout):** перевірка наявності товарів на складі (`stock`), збереження замовлення в атомарній транзакції (`transaction.atomic`).
- **Платіжна система Stripe:** створення Stripe Checkout Session та редірект на захищену оплату.
- **Сповіщення:** автоматична відправка листа-підтвердження на електронну пошту після замовлення.
- **Асинхронні views:** реалізація неблокуючих маршрутів з асинхронними запитами до бази (`aget`, async generator).
- **Інтернаціоналізація (i18n):** повна підтримка англійської (`EN`) та української (`UK`) мов.
- **Тестування:** тестовий набір на `pytest` із фікстурами на `factory-boy`, моками зовнішніх сервісів (Stripe, Email) та покриттям коду > 90%.

## AI Usage (Використання штучного інтелекту)

У рамках виконання практичного завдання було використано ШІ (AI Collaboration) для наступних завдань:

1. **Code Review трьох ключових контролерів:**
   - Детальний аналіз views `order_create`, `cart_add` та `async_book_list`.
   - Виявлення потенційних проблем (race condition при списанні залишків, оптимізація запитів до БД через `select_related`).
   - Результати збережено у файлі `AI_REVIEW.md`.

2. **Генерація docstrings:**
   - Створено вичерпні описи (PEP 257) для всіх CBV та FBV контролерів у додатку `store`.

3. **Генерація тестів моделей:**
   - Згенеровано тести для моделей `Book`, `Order`, `OrderItem` із перевіркою строкового представлення, методів підрахунку сум та оновлення залишків.
   - Усі тести перевірено, адаптовано під фабрики `factory-boy` та промарковано коментарем `# Generated with AI, reviewed and modified`.
   - Файл: `store/test_ai_models.py`.

4. **Промпти та взаємодія:**
   - Усі промпти, що використовувалися для роботи з ШІ, задокументовано у файлі `AI_PROMPTS.md`.
